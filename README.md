# 拾序 · 安卓个人清单

基于 Vue 3、Vite 和 Capacitor 的安卓个人清单应用，计划接入钉钉工作台和 DeepSeek 对话助手。

## 本地运行

```sh
npm install
npm run dev
```

## Pi 助手

在日历页 Pi 面板右上角配置模型 API Key，支持 DeepSeek 与智谱 GLM，App 直连模型服务的 HTTPS 接口、不走中间服务器。真机上密钥保存在 Android 安全存储（Keystore 加密），浏览器预览仅保留在当前页面内存中，不会写入日历数据或日志。

## 钉钉日历同步

设置里「钉钉同步」用钉钉开放平台**企业内部应用**凭证直连拉取日程（只读，不会改动钉钉里的日程）。接入步骤：

1. 在 [钉钉开放平台](https://open-dev.dingtalk.com/) 创建「企业内部应用」（需要公司管理员权限），拿到 Client ID 与 Client Secret。
2. 为应用申请权限点：「通讯录个人信息读权限」「个人手机号信息」（用于按手机号定位你自己的账号）、「日历」相关的日程读权限。
3. 应用的可见范围需包含你本人。
4. 在拾序的「钉钉同步」里填入 Client ID、Client Secret 和注册钉钉的手机号，保存后立即试同步；之后每次打开 App 会自动同步今天起 7 天内的日程，也可手动「立即同步」。

密钥只保存在 Android 安全存储（Keystore），不进入日历数据库、日志或代码仓库；App 直连 `api.dingtalk.com` / `oapi.dingtalk.com`，没有中间服务器。日程按钉钉日程 ID 去重合并，只同步标题与时间，本地的完成状态、象限标注和 PDCA 记录不会被覆盖。

## 数据本地化

日历、PDCA、语音转写和反思全部保存在手机本机（Android SQLite）。应用没有任何自有后端：唯一的对外请求是 Pi 对话时发给所选模型服务商的内容（对话消息、最近聊天记录和当天日程摘要），不包含 PDCA 正文、语音转写和反思。语音识别由 Android 系统语音服务处理。
